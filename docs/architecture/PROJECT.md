# PROJECT.md — RSS Reader 产品意图

> 本文档定义 RSS Reader 阅读器子项目的产品定位、核心体验和明确拒绝的边界。

## 这是什么

RSS Reader 是一个**本地优先**的 RSS 阅读器桌面应用。它让用户订阅和管理 RSS/Atom 源，以简洁的阅读体验消费文章内容。

## 为谁而做

- 有长期 RSS 阅读习惯的用户
- 关注隐私和数据自主权的用户（数据完全本地存储）
- 需要轻量、快速启动的桌面阅读工具的用户

## 核心体验

1. **订阅管理**：添加 RSS/Atom 订阅源，通过文件夹组织归类
2. **文章阅读**：三栏式布局（侧边栏→文章列表→阅读区），支持键盘快捷键快速浏览
3. **状态标记**：已读/未读、收藏、稍后阅读
4. **全文搜索**：通过 FTS5 实现文章标题和内容的全文检索
5. **过滤规则**：自动对文章执行标记已读、收藏、稍后阅读等操作
6. **OPML 导入/导出**：与其他阅读器之间迁移订阅数据
7. **桌面原生体验**：通过 Wails 打包为 Windows 桌面应用，支持系统托盘、原生窗口控制

## 架构原则

1. **本地优先（Local-First）**：数据始终在本地，网络仅用于抓取 RSS Feed
2. **极简依赖**：前端仅依赖 React + lucide-react，无 UI 组件库
3. **单进程桌面体验**：Wails 桌面壳管理 Go 后端子进程，用户无需手动启动服务
4. **读写分离**：阅读器（Reader）与路由工具（Routing Tool）是两个独立的应用，通过 OPML 文件共享订阅数据

## 数据策略

- 阅读器使用独立的 SQLite 数据库（`%LOCALAPPDATA%\RSSReader\reader.db`）
- 路由工具使用独立的 SQLite 数据库
- 两个应用之间通过 OPML 导入/导出或 Feed URL 共享订阅
- 不提供数据迁移工具，用户选择重新开始或手动导入
