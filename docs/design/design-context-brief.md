# Flore — RSS Reader 设计上下文品牌分析

## 项目定位
**Flore** 是一款「本地优先」的 RSS 阅读器桌面应用，同时提供 Web 版。它不是社交阅读器，也不是新闻聚合器，而是面向重度阅读者的个人知识管理工具。

核心价值：
- 本地优先：数据保存在本地，隐私可控
- 深度阅读：支持 RSS 正文、抓取全文、网页预览、浏览器打开多种阅读模式
- 知识管理：文件夹分组、稍后阅读、收藏、自动过滤规则
- 桌面原生体验：Wails 桌面壳，有窗口标题栏、系统托盘感

## 当前技术栈
- 前端：React 19 + Vite 6 + TypeScript 5
- 样式：CSS 变量 + inline style（无 Tailwind / CSS-in-JS）
- 图标：lucide-react
- 后端：Go (Gin + GORM + SQLite)
- 桌面壳：Wails v2.13+

## 当前设计系统（从 index.css 提取）

### 色彩
- 背景层级：`#FAFAFA` (canvas) / `#FFFFFF` (surface) / `#F2F2F2` (elevated)
- 文字：`#1A1A1A` (primary) / `#6E6E6E` (secondary) / `#A0A0A0` (muted)
- 主色：低饱和紫 `#7B68EE` → hover `#6A5ACD`
- 强调：未读蓝 `#3B82F6` / 成功绿 `#22C55E` / 警告橙 `#F59E0B` / 危险红 `#EF4444`
- 按钮：Obsidian 风格的深色按钮 `#1A1A1A`

### 字体
- Sans: Inter, "SF Pro Display", "Segoe UI", "PingFang SC", "Microsoft YaHei"
- Mono: JetBrains Mono, "Fira Code"
- Serif: "Noto Serif SC", "Source Han Serif SC"

### 圆角 / 间距
- radius: 4px / 6px / 8px（克制的桌面工具感）
- shadow: 极淡的投影，1–4px 级别

## 当前核心界面
1. **三栏布局**：Sidebar（订阅源/文件夹）→ ArticleList（文章列表）→ Reader（阅读器）
2. **Sidebar**：树形文件夹 + 订阅源列表，支持右键菜单、搜索、设置入口
3. **ArticleList**：文章卡片列表，支持多选、筛选（全部/未读/收藏/稍后阅读）
4. **Reader**：阅读视图，可切换字体/字号/行高/主题/最大宽度
5. **设置弹窗**：通用、订阅源、过滤规则、关于、数据备份
6. **多个模态弹窗**：添加订阅源、编辑、移动、导入 OPML、导出文章、重命名、确认对话框

## 实际 UI 文案（中文）
- 全部文章 / 未读 / 收藏 / 稍后阅读
- 选择一篇文章开始阅读 / 从左侧订阅源选择来源，再点击文章即可阅读
- 设置：通用 / 订阅源 / 规则过滤 / 关于
- 添加订阅源 / 导入 OPML / 导出 OPML / 导入数据库 / 导出数据库
- 检测可用性 / 取消订阅 / 在全部文章隐藏
- 阅读模式：默认字体 / 默认字号 / 默认行高 / 最大宽度 / 字间距 / 阅读主题

## 品牌风格候选分析

### 1. Obsidian（知识库工具风格）
**特征：**
- 深色主题为默认，强调"第二大脑"感
- 紫色调主色（Obsidian 品牌紫 #7B68EE 与当前主色意外一致）
- 极高的信息密度，边框/分隔线精细
- 左侧导航树 + 中间内容区 + 右侧辅助面板
- 插件/设置弹窗复杂但有序

**适合点：**
- RSS 阅读器本质上是知识入口，Obsidian 用户是目标人群
- 当前三栏布局与 Obsidian 高度相似
- 当前紫色调与 Obsidian 品牌色自然契合
- 深色主题更护眼，适合长时间阅读

**参考：**
- 左侧文件树：文件夹可折叠、拖拽、右键菜单
- 标签页/面包屑导航
- Command Palette 快速操作
- Graph view 的概念可迁移为"阅读关系图"

### 2. Apple（原生精致风格）
**特征：**
- 大量留白、圆角、毛玻璃效果
- SF Pro 字体、系统级控件
- 浅色主题为主，强调内容本身
- Mail / Notes / Safari 的设计语言
- 动画流畅自然，不打扰阅读

**适合点：**
- Wails 桌面应用天然接近原生应用
- 阅读器需要聚焦内容，Apple 的"内容优先"哲学契合
- 中文用户熟悉 Apple 设计
- 适合轻度/普通用户

**参考：**
- Apple News 的杂志感排版
- Apple Mail 的三栏布局
- Notes 的简洁侧边栏
- Safari 阅读器模式的排版

### 3. Microsoft（Fluent Design / Office 风格）
**特征：**
- 清晰的层级、命令栏（Ribbon/Command Bar）
- 蓝色品牌色、直角+小圆角混合
- 生产力工具感、企业级可靠性
- Outlook / OneNote / Edge 的设计语言

**适合点：**
- RSS 阅读器是生产力工具，Microsoft 风格传达可靠
- Windows 用户群体大
- 适合有复杂管理需求的用户

**参考：**
- Outlook 的邮件列表和阅读窗格
- OneNote 的笔记本/分区/页面层级
- Edge 的收藏夹/阅读列表
- Fluent Design 的亚克力/Reveal 效果

### 4. 其他值得参考的品牌风格

#### 4.1 Notion（模块化工作空间）
- 特点：块级编辑器、数据库视图、侧边栏工作区
- 适合点：可将 RSS 文章转化为知识库页面
- 风险：过于复杂，偏离 RSS 阅读器的轻量本质

#### 4.2 Reader by Readwise（阅读专注）
- 特点：稍后阅读 + RSS 二合一，强调阅读体验
- 适合点：RSS 与阅读后的高亮/笔记整合
- 参考：文章卡片设计、阅读进度、标签系统

#### 4.3 Feedly（专业 RSS 聚合）
- 特点：杂志式布局、AI 分类、团队协作
- 适合点：传统 RSS 用户熟悉
- 风险：界面偏复杂，不够现代

#### 4.4 Inoreader（高效信息处理）
- 特点：高密度列表、规则过滤、搜索强大
- 适合点：与当前过滤规则功能契合
- 参考：规则编辑器、批量操作

#### 4.5 Reeder（macOS 经典 RSS）
- 特点：极简美学、半透明侧边栏、优雅动画
- 适合点：桌面 RSS 应用的标杆
- 参考：文章列表的卡片/行视图切换、阅读排版

#### 4.6 Linear（现代开发工具美学）
- 特点：深色主题、紫色强调、快捷键文化、极速感
- 适合点：开发者用户会喜欢
- 参考：命令面板、快捷键提示、状态微标

#### 4.7 Craft（精美文档）
- 特点：卡片式、柔和的阴影、优雅的排版
- 适合点：提升阅读体验的视觉质感
- 参考：文章卡片的 hover 效果

## 设计建议方向

基于项目特色和候选品牌分析，建议采用 **"Obsidian + Apple" 的混合风格**：

### 核心理由
1. **Obsidian 负责"知识工具"的身份认同**：深色主题、紫色调、左侧导航树、高密度信息
2. **Apple 负责"阅读体验"的内容质感**：留白、字体、圆角、动画、内容优先
3. **避免 Microsoft 的办公工具感**：过于企业化，不够个人化
4. **借鉴 Linear 的细节精度**：快捷键提示、状态微标、微交互动画
5. **借鉴 Reeder 的 RSS 专业感**：文章列表布局、阅读排版

### 具体设计建议
1. **默认深色主题**，但保留浅色/跟随系统选项
2. **主色保持紫色** `#7B68EE`，但增加一套更完整的紫色梯度
3. **左侧边栏采用 Obsidian 式的文件树**：可折叠文件夹、拖拽排序、hover 高亮
4. **文章列表采用 Reeder/Apple News 的卡片/紧凑切换**：未读有明显的紫色/蓝色指示
5. **阅读器采用 Safari 阅读器模式 + Apple Books 的排版**：衬线字体、舒适行高、主题切换
6. **模态弹窗和设置采用 Apple 风格**：大圆角、毛玻璃背景、清晰的分组
7. **增加命令面板（Command Palette）**：Obsidian/Linear 风格，提升效率
8. **状态微标和图标系统**：Linear 风格的精致小图标
