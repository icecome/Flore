# 2025-08-01 Work Log

## Infinite Scroll Implementation for ArticleList

Fixed the infinite scroll / auto-load functionality in ArticleList.tsx.

### Problem
The auto-load trigger was calling `onFetch` which pointed to `handleFetch`. `handleFetch` resets the article list (calls `fetchItems(0)`), causing infinite scroll to clear loaded content instead of appending new items.

### Solution
1. Added `loadMoreOffset` state in App.tsx to track pagination offset
2. Added `fetchMoreItems()` function in App.tsx that calls `fetchItems(nextOffset)` without resetting
3. Added `onFetchMore` prop to ArticleList.tsx
4. Updated IntersectionObserver to call `onFetchMore` instead of `onFetch`
5. Fixed duplicate `className` attribute in ArticleRow JSX
6. Fixed `useState` import in ArticleList.tsx
7. Fixed AddSourceModal to accept `folders` prop

### Files Modified
- `apps/web/src/App.tsx`
- `apps/web/src/components/ArticleList.tsx`
- `apps/web/src/components/AddSourceModal.tsx`
