## 窗口状态图标不一致修复（二次修复）

- **第一版**：`GetWindowState()` 从持久化 `window-state.json` 读取。但方向反而反转了。
- **根因**：持久化的是「上次保存的状态」，但 Wails 在 `Frameless: true` + 最小化到托盘退出时，实际保存的是 `maximised: true`（退出前窗口是最大化的），而下次启动时 `options.Maximised` 让窗口启动最大化——但 `WindowIsMaximised()` 启动初期返回 `false`（状态未同步），导致图标显示错误。
- **最终修复**：
  - `useEffect` 改为 **async 内部函数** `initMaximized()`，先 `await GetWindowState()`（持久化状态作默认值），再 `await WindowIsMaximised()`（运行时实际状态作优先值）
  - 取优先级：`WindowIsMaximised`（运行时实际状态）> `GetWindowState`（持久化状态）
  - `callWindow` 内 `WindowToggleMaximise` 后的状态同步：`app.WindowIsMaximised?.()` 改为 `await app.WindowIsMaximised?.()`
  - `api.ts` 类型定义：`WindowIsMaximised` 和 `GetWindowState` 改为 `Promise` 返回类型
  - 前端重新构建，复制到 `apps/desktop/frontend/dist/`
- **状态**：Go build ✓，TypeScript ✓，测试 ✓

## 设置→订阅源表格滚动失效修复（21:23）
- **现象**：今日把表格从 `max-h-[640px]` 改成 `flex-1 min-h-0 overflow-y-auto` 后，表格无法滚动、底部行被截断。
- **根因**：flex 高度约束链断裂。`SettingsSourcesTab.tsx` 中滚动区（第143行 `flex-1 min-h-0 overflow-y-auto`）的父级——表格外框（第126行）只是普通 `overflow-hidden` 块级 div，不是 flex 容器、也没有 `flex-1`；根 div 用的是 `h-full` 而非 `flex-1`。导致 `flex-1` 在块上下文中无效、滚动区高度=内容高度，被 SettingsModal 第945行 `overflow-hidden` 裁掉。
- **修复（最小变更，3 处 className）**：
  1. 根 div：`h-full`→`flex-1`（成为 content 容器的 flex 子项，获得有界高）。
  2. 表格外框：`overflow-hidden rounded-lg...`→`flex flex-1 min-h-0 flex-col overflow-hidden rounded-lg...`（让内部滚动区真正生效）。
  3. 表头：`grid grid-cols-12 ...`→加 `shrink-0`（固定表头不随滚动消失）。
- **验证**：tsc --noEmit 通过；vite build 成功；同步到 `apps/desktop/frontend/dist`。
- **通用教训（沉淀）**：在 flex 列里做"内部滚动"必须满足链路：`overflow-hidden` 祖先 + 每一层 `min-h-0` + 滚动容器父级是 `flex flex-col` 且自身 `flex-1`，滚动容器 `flex-1 min-h-0 overflow-y-auto`。只给滚动容器加 `flex-1` 而父级不是 flex 是常见陷阱。
