# Flore 设置面板 UI 重新设计方案

## 一、设计目标

基于现有 Flore 设置面板的代码实现（`SettingsModal.tsx` + 9 个标签页组件），在不改变功能范围的前提下：

1. 统一 9 个导航标签的视觉语言
2. 将"数据管理"标签中原有的多层弹窗交互改为内嵌式表格/卡片
3. 优化信息层次与交互流程，提升可读性和操作效率
4. 保持与现有主题风格一致（颜色、字体、圆角、间距）

## 二、现有设计语言提取

从代码中梳理出的基础设计系统：

| 维度 | 现状 | 设计稿延续 |
|------|------|-----------|
| 布局 | 左侧 200px 导航 + 右侧内容区 | 保留，优化标签项间距与 active 状态 |
| 组件 | Section 分组 + Row 行 + Toggle/Switch + Select + Input | 延续，增加卡片式 Section 背景 |
| 按钮 | `border border-border rounded-md px-3 py-1.5 text-[13px]` | 主操作用紫色填充，次操作用描边 |
| 字体 | Inter，正文 13.5px，小标题 14-15px | 延续 |
| 配色 | CSS 变量：`--primary` / `--secondary` / `--muted` / `--accent` | 紫色强调色 `#5046E5`，中性灰文字 |
| 圆角 | 8-12px | Section 12px，按钮/输入框 6px |

## 五、数据管理标签设计

### 5.1 信息架构

分为 3 个 Section 卡片：

1. **备份与恢复**
   - 立即备份（主按钮）
   - 备份管理（次按钮，点击后展开内嵌表格）
   - 刷新（次按钮）
   - 空状态提示 / 备份列表表格
2. **备份策略**
   - 最大保留数量（数字输入框，默认 10）
   - 最大保留天数（数字输入框，默认 30）
   - 启用自动备份（Switch，默认关闭）
   - 立即清理过期备份（次按钮）
3. **文章留存策略**
   - 保留天数（数字输入框，默认 0）
   - 最大文章数（数字输入框，默认 0）
   - 排除已收藏文章（Checkbox，默认勾选）
   - 排除稍后读文章（Checkbox，默认勾选）
   - 立即清理过期文章（次按钮）

### 5.2 内嵌备份列表表格

替代原有的"备份管理"弹窗：

| 备份名称 | 创建时间 | 大小 | 操作 |

| backup-2026-08-01.zip | 2026-08-01 14:32 | 24.5 MB | 下载 恢复 删除 |

列宽规范：

### 5.3 按钮层级

| 按钮 | 样式 | 用途 |
|------|------|------|

| 立即清理过期文章 | 白色填充 + 灰色描边 | 破坏性/清理操作 |

## 九、响应与适配

- 弹窗尺寸固定，内容区高度不足时可内部滚动
- 侧边栏标签文字较长时（如"通知与驻留"），保持单行显示，可适当缩小字号或增加侧边栏宽度
- 表格操作列在窄屏下可折叠为"更多"下拉菜单

## 十、交互说明

1. **标签切换**：点击侧边栏标签切换右侧内容区，无页面刷新
2. **备份管理展开**：点击"备份管理"按钮，在当前 Section 下方展开内嵌表格；再次点击收起
3. **备份操作**：每行提供下载、恢复、删除入口，删除需二次确认
4. **自动备份**：开启后显示间隔选择器（可后续扩展）
5. **清理操作**：点击后显示确认提示，防止误操作
